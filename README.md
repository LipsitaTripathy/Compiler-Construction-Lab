# Compiler Construction Lab

## About
This repository contains C++ programs implemented as part of the Compiler Construction lab assignment. It demonstrates basic programming concepts and compiler design techniques.

## Programs Included

1. **Fibonacci Series** – Generates the Fibonacci series up to N terms.
2. **Lexical Analysis** – Identifies tokens in source code, such as keywords, identifiers, operators, and numbers.
3. **Parse Tree of Arithmetic Expression** – Constructs and displays a parse tree for an arithmetic expression.
4. **Source Code Optimization** – Demonstrates operator strength reduction, dead code elimination, and frequency reduction.

## Programming Language
- C++

## Purpose
To understand and implement fundamental concepts related to Compiler Construction through practical programs.
